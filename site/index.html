Understanding the signals behind financial health.

An end-to-end fintech data platform exploring how transaction behaviour can highlight potential signs of financial stress. Built from API ingestion through to tested, decision-ready data models.

View project on GitHub ↗ About the project

The question

Can spending concentration and repeated negative monthly cash flow act as useful indicators of financial pressure? This project builds the data pipeline and analytical models needed to explore that question. It uses synthetic Plaid Sandbox data, so its risk signals are illustrative rather than validated predictions about real customers.

How it works

Plaid API→Python→Cloud Storage→BigQuery→dbt→Airflow

Tools: Python · Google Cloud Storage · BigQuery · dbt · Apache Airflow · Docker · GitHub Actions
