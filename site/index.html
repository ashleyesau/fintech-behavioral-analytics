01 / The project

Turning transaction data into useful signals.

The project simulates a fintech analytics platform using synthetic data from two Plaid Sandbox institution profiles.

The goal is to build a dependable data pipeline that transforms raw financial activity into clear, testable behavioural indicators.

The analytical focus includes merchant spending concentration, monthly cash flow and repeated negative cash-flow periods. These indicators are brought together in downstream data models for further analysis.

Important context

Plaid Sandbox data is synthetic. The project demonstrates data engineering and modelling practices, not validated predictions about real customers.

03 / Engineering

Key decisions and lessons.

The work focused on data reliability, clear model logic and understanding how each part of the pipeline behaves.

Data ingestion

Reliable cursor-based sync

Advance the Plaid cursor only after data is successfully written, allowing ingestion to resume from the last successful position.

Data modelling

Preserving inactive months

Build an account-month spine so months with no transactions remain visible in cash-flow analysis.

Data quality

Consistent staging models

Standardise types, null handling and source fields before applying downstream business logic.

Debugging

Investigating unexpected results

Resolve issues involving partition overwrites, SQL NULL handling and ambiguous column references.

04 / Scope

A focused engineering study.

The emphasis is on the data pipeline and analytical foundations.

The project uses synthetic Sandbox data and does not claim real-world predictive accuracy. A live dashboard, production-grade access controls and centralised cursor persistence are outside the current scope.
